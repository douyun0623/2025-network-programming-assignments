# HW03: TCP 파일 전송 및 진행률 표시 프로그램

## 프로젝트 개요

이 프로젝트는 TCP/IP 소켓 통신을 이용한 파일 전송 프로그램입니다. 클라이언트는 명령행 인수로 지정된 파일을 서버에 전송하며, 서버는 파일을 수신받는 진행률을 콘솔 창에 실시간으로 표시합니다.

가장 핵심적인 기능은 `\r` (Carriage Return)을 사용하여 콘솔 화면이 스크롤되지 않고 한 줄에서 퍼센트(%)가 동적으로 갱신되도록 구현한 것입니다.

<br>

## 주요 기능

- **TCP/IP 기반 파일 전송**: 클라이언트와 서버가 TCP 소켓을 통해 연결하고 파일을 안정적으로 전송합니다.
- **명령행 인수를 통한 파일 지정**: 클라이언트는 전송할 파일의 이름을 명령행 인수(Command-line argument)로 전달받습니다.
- **실시간 진행률 표시 (Non-scrolling)**: 서버는 파일 수신 상태를 퍼센트(%)로 표시하며, 콘솔의 한 줄에서 숫자가 갱신되어 스크롤이 발생하지 않습니다.
- **파일 무결성 검증**: 전송된 파일(예: 동영상)이 오류 없이 원본과 동일하게 수신되었는지 확인 가능합니다.

<br>

## 실행 방법

### 1. 서버 실행

1.  서버 프로그램을 컴파일합니다.
2.  콘솔 창에서 실행 파일을 실행하면 클라이언트의 접속을 대기합니다.
    ```bash
    C:\HW03_FileTransfer> server.exe
    ```

### 2. 클라이언트 실행

1.  클라이언트 프로그램을 컴파일합니다.
2.  콘솔 창에서 실행 파일 뒤에 **전송할 파일 이름**을 인수로 넣어 실행합니다.
    ```bash
    # 예시: MyMovie.mp4 파일을 서버로 전송하는 경우
    C:\HW03_FileTransfer> client.exe MyMovie.mp4
    ```
